# Registering the Wazuh Agent with the Manager

## Overview

After installing the Wazuh Agent, it must be registered with the Wazuh Manager before it can send security events. During registration, the Wazuh Manager generates a unique authentication key that securely identifies the agent. Once the key is imported into the Windows Agent, the agent can establish a trusted connection with the manager and begin sending security data.

---

## Objectives

- Create a new agent on the Wazuh Manager.
- Generate an authentication key for the agent.
- Import the authentication key into the Windows Agent.
- Configure the Wazuh Manager IP address.
- Restart the Wazuh Agent service.
- Verify that the agent successfully connects to the Wazuh Manager.

---

# Part 1 – Generate the Agent Key on the Wazuh Manager

## Step 1 – Open the Agent Management Utility

On the Ubuntu server, run:

```bash
sudo /var/ossec/bin/manage_agents
```

---

## Step 2 – Add a New Agent

From the menu, select:

```text
A) Add an agent
```

Enter the following information:

| Field | Example |
|--------|---------|
| Agent Name | WindowsHost |
| IP Address | Leave blank (or specify a static IP if required) |
| Agent ID | Automatically assigned |

After entering the information, confirm the registration.

---

## Step 3 – Extract the Agent Key

Return to the main menu and select:

```text
E) Extract key for an agent
```

Enter the Agent ID that was created.

The utility displays a long authentication key similar to:

```text
MDAxIFdpbmRvd3NIb3N0IGFueS...
```

Copy the entire key. It will be imported into the Windows Agent.

---

# Part 2 – Import the Key into the Windows Agent

## Step 4 – Open Wazuh Agent Manager

On the Windows system:

- Open the **Start Menu**.
- Search for **Wazuh Agent Manager**.
- Launch the application with administrator privileges.

---

## Step 5 – Import the Authentication Key

Paste the authentication key generated by the Wazuh Manager into the **Authentication Key** field.

Click **Save** or **Apply**.

---

## Step 6 – Configure the Manager Address

Enter the IP address of the Ubuntu server running the Wazuh Manager.

Example:

```text
192.168.1.120
```

Save the configuration.

---

## Step 7 – Restart the Wazuh Agent

Restart the Wazuh Agent service.

Using Windows Services:

1. Open **services.msc**
2. Locate **Wazuh Agent**
3. Select **Restart**

Or using PowerShell:

```powershell
Restart-Service WazuhSvc
```

---

# Part 3 – Verify Agent Registration

Log in to the Wazuh Dashboard.

Navigate to:

```text
Agents → Summary
```

Verify that:

- The Windows agent appears in the agent list.
- The agent status is **Active**.
- The connection status is **Connected**.
- Recent security events are being received.

---

## Expected Outcome

After completing these steps:

- The Windows Agent is successfully registered with the Wazuh Manager.
- Secure communication between the agent and manager is established.
- The agent appears as **Active** in the Wazuh Dashboard.
- The Windows endpoint begins sending security events for analysis.

---

# Common Troubleshooting and Expected Errors

| Error | Possible Cause | Solution |
|-------|----------------|----------|
| Invalid authentication key | Key copied incorrectly. | Copy the complete authentication key again and re-import it. |
| Agent not appearing in Dashboard | Agent service is not running. | Verify that the Wazuh Agent service is running. |
| Agent status is Never Connected | Incorrect Manager IP address. | Verify the Manager IP address in the agent configuration. |
| Agent status is Disconnected | Network connectivity issue. | Verify that the Windows host can communicate with the Wazuh Manager. |
| Duplicate agent name | An agent with the same name already exists. | Remove the existing agent or use a unique agent name. |
| Connection refused | Wazuh Manager is not running or required ports are blocked. | Verify the Manager service and firewall configuration. |
| Invalid Agent ID | Incorrect Agent ID selected during key extraction. | Extract the key using the correct Agent ID. |

# Key Takeaways

- Every Wazuh Agent requires registration before it can communicate with the Wazuh Manager.
- Each registered agent receives a unique authentication key that establishes trust with the manager.
- Accurate configuration of the Manager IP address is essential for successful communication.
- An active agent in the Wazuh Dashboard confirms successful registration and secure connectivity.
